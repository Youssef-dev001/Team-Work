# Team Progress Platform

منصة داخلية لمتابعة أعضاء الفريق والمهام الأسبوعية والواجبات ونسب التقدم.

## هيكل المشروع

- `index.html` — الصفحة العامة وتقدم الفريق
- `login.html` — تسجيل الدخول
- `dashboard.html` — لوحة العضو
- `admin.html` — لوحة تحكم الـ Admin
- `css/style.css` — التصميم العام
- `css/dashboard.css` — تصميم لوحات التحكم
- `js/config.js` — إعدادات Supabase
- `js/auth.js` — تسجيل الدخول والصلاحيات
- `js/public.js` — بيانات التقدم العامة
- `js/dashboard.js` — لوحة العضو
- `js/admin.js` — لوحة الإدارة
- `js/utils.js` — وظائف مساعدة
- `supabase/schema.sql` — جداول وقواعد قاعدة البيانات

## التشغيل

1. افتح المشروع في VS Code.
2. أنشئ مشروع Supabase.
3. نفّذ `supabase/schema.sql` داخل SQL Editor.
4. ضع بيانات Supabase في `js/config.js`.
5. افتح `supabase/migration_premium_tasks.sql` وانفّذ محتواه في Supabase SQL Editor لإضافة دعم روابط الفيديو المتعددة، مع الحفاظ على روابط الفيديو القديمة.
6. ارفع ملفات المشروع المحدّثة إلى الاستضافة. لا تحتاج إلى تغيير إعدادات `js/config.js` إذا كان الربط الحالي مع Supabase يعمل.

## التحديثات في النسخة المحسّنة

- واجهة فاتحة بطابع Premium، بطاقات أنعم، ظلال خفيفة، حركات انتقالية متدرجة، وتصميم متجاوب.
- خط Alexandria للعناوين والواجهة العربية، مع IBM Plex Sans Arabic كبديل.
- محرر المهمة يدعم تعيينها لأكثر من عضو من شاشة واحدة، مع متابعة مستقلة لكل عضو للحالة والإنجاز.
- إمكانية إضافة أكثر من رابط فيديو/مصدر للمهمة، وتظهر الروابط كعناصر واضحة داخل تفاصيل المهمة.
- **مهم:** عند نشر النسخة المحدّثة، نفّذ ملف `supabase/migration_premium_tasks.sql` مرة واحدة قبل استخدام حقل الفيديوهات المتعددة؛ وإلا سيرفض Supabase حفظ العمود الجديد.

> لا تضع كلمات المرور الحقيقية داخل ملفات JavaScript أو GitHub.
